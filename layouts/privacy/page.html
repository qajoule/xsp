データの扱い

読み込んだアーカイブをサーバーへ送る処理は、このサイトに実装されていません。以下は、その内訳です。

どこで処理するか
ブラウザの中だけです。ファイルは File API で直接読み込み、画面の解析結果はメモリ上で扱い、タブを閉じると消えます。ご自身で保存したファイルやクリップボードの内容は残ります。
通信が起きる場面
グラフの描画ライブラリや日本語解析用の辞書などを、このサイトから読み込みます。投稿の内容が通信に乗ることはありません。CSP の connect-src を 'self' に固定しているため、それ以外の接続先はブラウザが拒否します。
端末に保存するもの
表示テーマの選択（light / dark）だけを localStorage に保存します。投稿本文・ユーザー名・ファイル名は保存しません。
読まないファイル
DM・私信のファイルは開きません。画像・動画も読み込みません。いいね・フォロー・フォロワー・ブロック・ミュート・Grok の会話は、該当するファイルを端末内で読み取り、件数だけを集計します。
外部AIへ渡す場合
コーパスのダウンロード、コピー、Gemini Notebook などへのアップロードを選んだ場合、その時点からは利用先サービスのデータポリシーが適用されます。
アクセス解析
導入していません。Cookie も使いません。
